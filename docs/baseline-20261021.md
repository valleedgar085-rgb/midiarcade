## What the baseline implies for later phases

- `sectionRoleEvolution` fails in every song, which suggests the evaluator threshold may be miscalibrated rather than 42 independent failures. Check this before changing arrangement code (Phase 3).

- Groove-pocket refinement never fires in the lab, so it's worth checking whether it's dead in practice (Phase 4).
