# MIDI Arcade — Claude Code project guidance

@AGENTS.md

The canonical developer skills are in `.agents/skills/`. Claude Code slash-skill entry points are in `.claude/skills/` and refer to the same canonical sources. Before melody, groove, hook or arrangement development use `/midi-composition-review`; for hard-hitting bass, 808s and jumpy kick-locked grooves use `/midi-bass-groove-director`; before Web Audio fixes use `/midi-audio-diagnostics`; before branch integration or release claims use `/midi-safe-integration`.

See `docs/DEVELOPER_SKILLS_WORKFLOW.md`. Do not automatically install third-party skill packages, add runtime dependencies, or modify the approved audio baseline as part of this setup.
